Comment utiliser VisualTalk

Read in: English

Ce guide est écrit pour des personnes, pas pour des ingénieurs. Si vous savez copier-coller, vous pouvez configurer VisualTalk. Toute la configuration initiale tient en trois gestes : obtenir l'application, choisir un serveur, coller trois valeurs. Ensuite, tout se fait en boutons.

1. Obtenir l'application

Ordinateur (macOS, Windows, Linux) : téléchargez l'installateur de votre système depuis la page Téléchargements. Sur macOS, le premier lancement peut demander un clic droit → Ouvrir (les builds ne sont pas encore notariés — la page Téléchargements l'explique).

Telephones et tablettes : l'application Android est en test fermé sur Google Play et l'application iOS est en examen chez Apple. En attendant leur sortie, tout ce guide fonctionne à l'identique sur ordinateur.

2. Choisir un serveur (une fois, environ cinq minutes)

VisualTalk ne possède aucun serveur de visioconférence — c'est tout l'intérêt. Vos réunions tournent sur un serveur que vous choisissez. Prenez l'un des deux :

Option A — LiveKit Cloud (offre gratuite, chez quelqu'un d'autre)

Créez un compte gratuit sur cloud.livekit.io, créez un projet, ouvrez le tableau de bord du projet. Il affiche trois valeurs : une URL (elle commence par wss://), une clé API et un secret API. Copiez-les trois quelque part. Vous avez fini cette étape.

Option B — votre propre serveur (le bundle gratuit, chez vous)

Téléchargez le zip self-hosted server stack depuis la page Téléchargements, décompressez-le, et suivez les deux commandes de son README (« Quick start »). Puis, en langage simple :

  • l'adresse est le numéro de téléphone du serveur ;
  • la clé API est un numéro de carte de membre ;
  • le secret API est le code PIN de cette carte.

Le serveur crée la carte et le PIN tout seul au premier démarrage et les écrit dans son propre carnet, un fichier nommé docker/.env. Vous ne les inventez jamais — vous les copiez. Dans le dossier du bundle, cette commande lit le carnet à voix haute :

python3 scripts/livekit-local.py creds

Elle affiche l'URL, la clé API et le secret API, prêts à copier. (Sans commande ? Ouvrez le dossier docker et ouvrez .env dans un éditeur de texte — sur Mac, appuyez sur Cmd+Maj+. dans le Finder une fois pour révéler les fichiers cachés.) L'adresse à utiliser dépend de l'endroit où tourne l'application :

L'application tourne sur…Collez cette adresse
Le même ordinateur que le serveurws://localhost:7880
Un téléphone ou une tablette sur votre Wi-Fi domestiquews://<adresse Wi-Fi de l'ordinateur serveur>:7880, par ex. ws://192.168.1.20:7880. La trouver — Mac : Réglages Système → Wi-Fi → Détails… → Adresse IP ; Windows : Paramètres → Réseau et Internet → votre connexion → Adresse IPv4. Démarrez le serveur avec --host pour que les téléphones l'atteignent.
Un émulateur Android sur l'ordinateur serveurws://10.0.2.2:7880

3. Prévenir l'application (une fois)

Dans VisualTalk, ouvrez Paramètres → LiveKit (l'icône engrenage en bas à gauche). Collez les trois valeurs dans URL du serveur LiveKit, Clé API et Secret API, puis appuyez sur Enregistrer la configuration. L'application sait maintenant appeler votre serveur. Pas de compte, pas d'inscription cloud, rien ne sort de chez vous. Traitez le secret API comme un mot de passe : ne le collez jamais dans une conversation, une capture d'écran ou un e-mail.

4. Votre première réunion

  • Nouvelle réunion en démarre une immédiatement. Copier le lien de la réunion vous donne une page visualtalk.app/j/… : envoyez-la à vos invités — elle affiche le code de salle avec un bouton copier.
  • Rejoindre sert à saisir un code de salle ou un lien d'invitation reçu.
  • Planifier place une réunion à une date ; elle apparaît ensuite sur votre tableau de bord à l'heure choisie, et les invitations fonctionnent pareil.
  • Avant d'entrer, l'aperçu montre votre caméra pour vérifier votre cadre et votre arrière-plan, choisir le bon microphone et la bonne caméra, et rejoindre en muet ou caméra éteinte si vous préférez (« Toujours afficher l'aperçu »).
  • En réunion, la barre d'outils contrôle le microphone, la caméra et le partage d'écran ; le panneau latéral contient la discussion et l'envoi de fichiers avec les autres participants.
  • Notes sur le tableau de bord est un bloc-notes personnel qui reste sur votre appareil.

5. Enregistrement et sous-titres (optionnel)

L'organisateur peut enregistrer une réunion. Avec le bundle Docker, les enregistrements arrivent dans docker/recordings/ sur la machine serveur et nulle part ailleurs ; l'onglet Enregistrements les liste. Si votre serveur fait tourner le module optionnel de reconnaissance vocale, des sous-titres apparaissent en réunion (ce module ne traduit qu'en anglais).

6. Quand ça se comporte mal (solutions en langage simple)

  • Un téléphone tourne en rond sur « Connexion… » → vous avez collé l'adresse « cet ordinateur ». Un téléphone a besoin de l'adresse Wi-Fi du tableau de l'étape 2.
  • « Unauthorized » ou une erreur d'authentification → la clé ou le secret a été retapé à la main avec une coquille. Copiez-collez plutôt ; aucune des deux valeurs ne contient d'espace.
  • Ça marchait hier mais pas aujourd'hui → le serveur dort. Relancez-le (avec le bundle : python3 scripts/livekit-local.py up).
  • Caméra ou micro muet → le système a demandé l'autorisation au premier usage et elle a été refusée. Ré-autorisez VisualTalk dans les réglages de confidentialité du système, puis relancez l'application.

Toujours bloqué ? Écrivez à kghemari@yahoo.com avec votre version de VisualTalk (Paramètres → À propos) et ce que vous voyez à l'écran. L'assistance est gratuite et au mieux de nos possibilités.

VisualTalk ne contient ni compte ni analytique, et l'éditeur ne voit jamais le contenu des réunions. Détails : politique de confidentialité.
